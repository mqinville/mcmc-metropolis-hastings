## 1. What this project is

STAT*4000 (Statistical Computing, University of Guelph, Fall 2026) group
project by **Félix Mainville** and **Matthew Kai Kai**. We study the
**Metropolis-Hastings (MH) algorithm**, hand-written in R, in two parts:

1. **Simulation study**: run MH repeatedly on targets with known truth (normal,
   gamma, lognormal) and measure how proposal distribution, step size, starting
   value, number of iterations, burn-in, and target shape affect performance.
   Metrics: acceptance rate, estimation accuracy, autocorrelation, effective
   sample size (ESS), Monte Carlo standard error, runtime.
2. **Environmental application**: use MH to sample from a distribution fitted
   to Ontario PWQMN 2025 **total phosphorus (TP)** data and estimate the
   exceedance probability P(TP > 30 ug/L) (Ontario PWQO for rivers/streams).
   The exact value under the fitted distribution is known, so it is a check.

Deliverables: a written report (`MCMC_Report.Rmd`, <= 20 double-spaced pages
excluding references/appendices) and a short presentation. The proposal is
`STAT4000 - Project Proposal (5).pdf`.

Key dates (2026): presentation finished ~Nov 27; presentations Dec 1 / Dec 3;
report draft ~Nov 30; **report due Dec 4**.

References: Chib & Greenberg (1995) "Understanding the Metropolis-Hastings
algorithm"; Rizzo (2019) *Statistical Computing with R* 2nd ed., Ch. 11 (the
course textbook, eq. 11.3 is the acceptance ratio used here).

## 4. The sampler: how it works (do not break this contract)

`mh_sampler(target, n_iter, x0, proposal)` returns
`list(x = <chain>, accept_rate = <num>, proposal = <name>)`.

- `target`: function of one number returning the **density on the raw scale**
  (may be unnormalised; 0 outside the support). NA/NaN counts as 0, so the
  candidate is rejected. Densities can underflow far in the tails; pick `x0`
  near the bulk. `target(x0)` must be finite and > 0.
- `n_iter` includes the starting value (`x[1] == x0`); `accept_rate` is over the
  `n_iter - 1` candidates.
- Acceptance: `r = f(Y) g(X_t | Y) / (f(X_t) g(Y | X_t))` (Rizzo eq. 11.3),
  accept if `runif(1) <= r` (no `min(1, r)` needed). Zero/undefined proposal
  density in the denominator rejects.
- `proposal` is a list of class `"mh_proposal"` with `draw(x)`, `q(to, from)`
  (= g(to | from)) and `name`. Built-ins in `R/proposals.R`:
  `normal_rw(sd)` (symmetric), `lognormal_rw(sd)` (multiplicative, positive
  targets only, asymmetric so it needs the Hastings correction),
  `gamma_independence(shape, rate)` (independence sampler; needs tails at
  least as heavy as the target). Custom proposals: any list with `draw` and `q`.
- The old `log_q`-style proposals are intentionally rejected (tested).
- The loop is a plain, readable `for` loop on purpose (course project: the
  algorithm must be inspectable). Do not vectorise or swap in a package sampler.
- `tests/testthat/fixtures/log_scale_chains.rds` holds reference chains from an
  earlier log-scale implementation; the raw-scale sampler must reproduce them
  exactly under `set.seed(123)`. Changing RNG call order (one `draw`, one
  `runif` per iteration, in that order) breaks reproducibility and this test.

## 5. Data and environmental-application facts

- Source: Ontario PWQMN 2025 CSV (`https://files.ontario.ca/moe_mapping/downloads/2Water/PWQMN/PWQMN_2025.csv`).
  **Latin-1 encoded** (the "u" in ug/L is a micro sign); read every column as
  character so `"<0.2"` survives. Use `read_pwqmn()`.
- Cleaning (`clean_tp()`): keep `Analyte == "Phosphorus; total"` (3,764 rows of
  120,441); strip the leading apostrophe on site IDs; drop 74 exact duplicate
  rows (same site/date/time/result); replace 20 below-detection-limit values
  (`<0.2`) with DL/2 = 0.1; flag (keep) 63 rows with lab remark codes.
  Result: **3,690 samples, 449 sites**, units ug/L.
- Descriptives: median 13.9, mean 46.5, sd 281, q90 77.6, q99 396.4, max 10,300,
  skewness 27.7, empirical P(>30) = 0.2653. Extremely right-skewed.
- Candidate fits (MLE, `fitdistrplus`), ranked by AIC: **lognormal**
  (meanlog 2.656, sdlog 1.384; P(>30) = 0.2952) >> Weibull (dAIC 933) >> gamma
  (dAIC 1954; shape 0.532, rate 0.01145; badly underestimates the upper tail).
  The lognormal is the chosen MH target. The gamma fit needs an explicit start
  (`shape = 0.5, rate = 0.5 / mean(x)`).
- Sensitivity checks already written: DL/2 vs left-censored MLE
  (`censoring_check()`), per-site medians (`site_median_check()`) because
  repeated samples at a site are not independent.
- Reproducibility: seed is **`set.seed(4000)`** everywhere. Keep it.
